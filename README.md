# ReisSmart

Lista de compras inteligente: compare preços entre mercados, escaneie códigos de barras, organize por categoria e acompanhe seu orçamento — tudo salvo localmente no seu celular.

Desenvolvido por Thiago de Souza Reis.

## Scripts

```bash
npm run dev       # ambiente de desenvolvimento
npm run build     # build de produção
npm run preview   # pré-visualização do build
npm run deploy     # publica no GitHub Pages
```
